# 裁判の期限（saiban-kigen）

逮捕・送致・勾留・控訴・上告・即時抗告・略式命令・少額訴訟・支払督促・再審などの場面を読んで、その期限（24時間・48時間・72時間・3日・1週間・10日・14日（2週間）・30日・2か月・5年）を当てる1日5問の学習ゲーム。正解したら、どの手続きか（刑事の捜査／刑事の裁判／民事の裁判）も選ぶ。裁判のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/saiban-kigen/>

- 中身は e-Gov 法令検索の刑事訴訟法（<https://laws.e-gov.go.jp/law/323AC0000000131>）第203・205・208・373・414・422・465条と、民事訴訟法（<https://laws.e-gov.go.jp/law/408AC0000000109>）第251・285・313・332・342・357・378・391・392・393条に書いてある期限だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。裁判所規則・少年事件・費用や手数料は省いています。公式の情報の代わりではありません。実際の手続きは、裁判所の案内や専門家に確かめてください。
- 2段目は、手続きの種類で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
